<h2 id="中文">🇨🇳 中文</h2>

### 📖 我们是谁

**BiuBox 是一个校园论坛网站。** 我们的目标是让学生可以**替代微信社交方式**，解决各公司生态不通以造成的种种社交麻烦。

<br/>

### 💬 独特的交流方式

在 BiuBox，**帖子不叫帖子，而是叫「话题」**。

> 若刷到自己感兴趣的话题，可以点进去查看**话题全文**，并且与其他同样对此话题感兴趣的人在**讨论区**讨论。
> **讨论区采用与短信一样的排布方式。**

<div align="center">

| 传统社交 | → | BiuBox |
| :---: | :---: | :---: |
| 帖子 | → | **话题** |
| 评论区 | → | **讨论区** |
| 信息流 | → | **短信式排布** |

<sub>帖子 → 话题　·　讨论区 = 像发短信一样聊天</sub>

</div>

<h2 id="english">🇬🇧 English</h2>

### 📖 Who we are

**BiuBox is a campus-forum website.** We aim to let students **replace the WeChat way of socializing**, solving the many social troubles caused by the fact that **each company's ecosystem is not connected to the others.**

<br/>

### 💬 A unique way to talk

In BiuBox, **a post is not called a post — it is called a "Topic."**

> If you swipe onto a topic you are interested in, you can tap in to **read the full topic**, and discuss it in the **discussion area** with others who are equally interested.
> **The discussion area is laid out just like SMS (text messages).**

<div align="center">

| Traditional social | → | BiuBox |
| :---: | :---: | :---: |
| Post | → | **Topic** |
| Comment list | → | **Discussion area** |
| Feed | → | **SMS-style layout** |

<sub>Post → Topic　·　Discussion = chat as easily as texting</sub>

</div>
